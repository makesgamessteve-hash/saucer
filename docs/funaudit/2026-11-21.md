## 2. Method

- **Accelerated sim:** `build/game/saucer_headless` (Release), fixed 60 Hz step, ~1,300-1,450 ticks/s per process (about 24x real time), 7 processes in parallel. Episode = **20 game minutes (72,000 ticks)** from a cold boot (title card), seeds 1-20.
- **Telemetry bridge (tools/funaudit/fun.lua):** wraps `saucer.test.press/axis` (input log + optional delay line), and a per-tick coroutine prints `FUNI` (every input onset: action, accepted, response ticks; resolved within 30 ticks), `FUNS` (1 Hz: mode, site, hold, hot, banked, hull, shield, suit, O2, threat, nearest sentry, input count, story clues, Echoes, bolts in flight, ship size), `FUNE` (every HUD message and sim fx, classified: alerted/locked/latched/stolen/retreat/teleport/bank/pickup; bolt near-misses; slipped detections; escaped latches/clamps), `FUNV` (loot value of the start sector).
- **Personas** (all through real command frames):
  - **Novice B_rand:** random valid inputs at 2-4 Hz across 5 axes and 18 buttons (camera/menu/XR snaps excluded), own LCG so the sim RNG is untouched.
  - **Human-proxy B_human:** the existing career autopilot (tools/playtest/bot.lua + career.lua, "mystery-first" policy: follow the Echo chain, Seat for guarded sites, sell at 6, sleep every 4 trips) with **every** press and stick change pushed through a 12 +-2 tick (200 +-33 ms) delay line; the bot's waits include the delay (CFG.delay=14). Reflexes (Jam a latched Snatcher, Boost against a Clamp) go through the same delay.
  - **Oracle B_opt:** the same policy, zero delay, exact state.
  - **SpamBot:** gets up, then presses Tractor every 6 ticks for 20 min.
  - **BeamOnly (dominant-strategy probe):** the career autopilot in the Villa only: no Seat, no Jammer reflex, no mystery.
  - 20 episodes each for rand/human/opt; 10 spam; 10 BeamOnly (20 in the A22CD batch).
- **Real-time pass:** `saucer --frame-stats` windowed 1280x720 under Xvfb (Mesa llvmpipe, no GPU, uncapped), 1 tick per frame, opt persona seed 1, 3 game minutes, 10,890 frames.
- **Boot/TTFA:** wall time from process launch to the tick-0 screenshot file (windowed, seed 42) and the tick of the first accepted move input.
- **Mobile web proxy:** the web build needs emscripten, which is not installed on the box, so the touch path was measured headless through the same engine touch code (tools/funaudit/touch.lua: sx_touch layout at 6 resolutions, touch Use latency, look-drag gain).
- **Prototypes:** sim changes behind tuning keys that are nil by default (`watcher.small_range`, `watcher.hurt_scale`), so main behaviour is byte-identical (game_slice, game_sentries, replay_slice_seed42, replay_coop_seed42 pass on the branch); the harness switches them on per batch with PROTO=A40CD. C (helm relay from the start) is applied by the harness only (sets `p.upgrades.beam_relay = 1` at tick 0).

| Skill metric | Saucer mapping used |
|---|---|
| W (survival / objective completion) | Mean of 4 session objectives in [0,1]: loot banked / 600 c (first upgrade tier + reserve), story clues / 2, Echoes decoded / 1, cargo integrity = 1 - items lost (stolen + left in retreat caches) / items pulled (0 if nothing pulled). Also reported raw: loot banked per minute, clues per run. |
| Threats | Watchers, Snatchers, Clamps, Warden (`state.sentries`), stun bolts in flight, oxygen on EVA |
| Health | max(1 - hull, 0.5 x (1 - shield), 1 - O2, hot items / 12 = loot at risk) |
| Near-miss | (a) a bolt whose closest pass is 1.0-1.5x the hit radius without hitting, (b) a sentry that went Alert on you and lost you before Lock (slipped detection), (c) a Snatcher latch or Clamp escaped before it took anything |
| Choices | Voluntary tool presses: tractor, scan, jam, decoy, shroud, spike, grapple, fold (size change), land, home/assist, map, boost (K=12; walking, look and Use excluded). Activity share by mode as a second entropy. |
| Tension T(t) | 0.5 x ThreatDensity (alert 0.5 / locked-latched-clamped 1 per sentry on you + 0.5 per bolt, /2, capped) + 0.2 x input rate (onsets/s / 6) + 0.3 x Health term above |
| Reward cadence | micro: pickup, Echo, beam lock, bank, scan, panel click, door sounds; meso: bank, "Got ...", STORY clue, Echo decode, upgrade, sale |
| Failure / retry | Fold Retreat (hull 0) and the EVA oxygen-out teleport; retry = failure to active control; re-engage = failure to back inside a site |
| Spam | SpamBot (Tractor only) and BeamOnly (Villa only, no tools) |
| Hurtbox ratio | bolt collider side area / drawn hull side silhouette (Villa lathe + dome, Seat lathe + seat), on foot: collider / body + helmet |
| Latency | sim ticks from injection to first state change, + one presented frame (present 8.0 ms measured) |
| Pillar sub-scores | each sub-metric is 1.0 inside the skill's target band and falls linearly to 0 at the skill's fail threshold (or a stated bound); a pillar is the mean of its sub-scores; composite = the skill's formula |

## 5. Top bottlenecks (mechanical causes)

1. **No threat in the competent path (M_pace, M_choice, M_flow).** `sim/sentry.lua` `watcher_sees()` returns false whenever the hull class is below the Watcher's size band (Seat class 1 vs band {2,4}), and Snatchers only wake for hot cargo within 22 m. The career policy dives every guarded site in the Seat, so 40 human/opt sessions of 20 minutes produced **0 alerts, 0 hits, 0 near-misses, 0 items lost**. On top of that, site 1 of the start sector has no sentries on any seed, so even a Villa-only player first meets a sentry at 9-14 minutes. The risk loop that the game is built on (hot loot that can be lost) never fires in normal play.
2. **Risk costs nothing (dominant strategy).** BeamOnly (Villa only, no tools, no Seat) takes ~100 bolt hits and 4-5 Fold Retreats per 20 minutes and still banks 1,038 c vs the careful human's 996 c (W ratio 1.03). Fold Retreat at danger 1 is free (`retreat_bill = { 0, 60, 120 }`), the hot cargo is left as a cache you can pick up again (`sim/hull.lua retreat`), the hull mends in open space (`hull_regen`) and is repaired at the trade terminal. Tool entropy is 0.21: competent play only presses Tractor (74-81%) and fold; scan, decoy, shroud, spike and grapple were never needed.
3. **Long dead stretches before and between rewards (M_loop cadence).** The first loot pull comes at 105 s (oracle) / 140 s (human), the first banked credit at a median 15.7 min, and 10% of reward gaps are longer than 108 s. 30% of the human's time is walking the Villa interior inside a site, between the helm and the Tractor Room, because the helm beam relay is a 180 c upgrade that the bot can't afford in the first session. A Fold Retreat sends you back to the trader, and it takes a median 72 s to fly back into a site.
4. **Collider bigger than the hull (M_fair).** `step_bolts()` tests the hull's bounding cylinder (diameter/2 + bolt radius, height/2 + bolt radius). The drawn Villa and Seat are lens-shaped, so the collider is 1.39x (Villa) and 1.71x (Seat) the silhouette: bolts visibly pass the rim and still hit.
5. **Thin impact feedback and HUD readability (M_feel, M_fair).** A stun-bolt hit is only a "hit" sound and a shield-bar change. There is no flash, camera impulse, hitstop or particles (the XR build gets a haptic pulse in view/xr.lua; the desktop build gets nothing). `view/audio.lua play()` has no pitch variation. Prompt and alert lines are drawn without a backing plate and drop to ~2.1:1 over lit derelict interiors (shots 10 and 03). The dome's frame struts cross the centre of the helm view (shots 10 and 11).

Healthy: latency (1 sim tick, ~25 ms to pixels), drop rate < 5%, TTFA 1.2 s, instant retry, all telegraphs >= 750 ms, no shake, frame time p95 14 ms even on a software renderer, touch buttons >= 48 px with no overlaps at 568x320.

## 8. Caveats on reliability

- **The bots are autopilots, not players.** Human and oracle share one route planner; "skill" differs only by the 200 ms delay line. So the skill gap mostly measures planning, which is the same for both, and the persona W numbers are close (0.86 vs 0.90). The autopilot does not play stealth: it does not dodge cones or time sweeps, so near-miss counts under prototype A are a lower bound.
- **W is my own composite** (thresholds 600 c / 2 clues / 1 Echo / integrity). The loot term saturates in 20 minutes, so W differences come mainly from story, Echo and integrity. Flow scores are sensitive to those thresholds.
- **Latency is in sim ticks** (inject -> state change) plus a measured present time. The real input path (SDL event -> command frame) and vsync were not measured on a real display; frame times are from Mesa llvmpipe under Xvfb, uncapped, so they are a CPU proxy, not GPU numbers.
- **Drop rate:** the 2.5-4.2% "slow Use" presses all occur in the trade panel and may be an artefact of delayed presses overlapping panel navigation.
- **Feedback channels** are counted from code (which sounds, messages, animations and HUD changes exist per event), weighted by how often each event happened in telemetry. Particles and camera feel were checked in code, not perceptually.
- **Hurtbox areas** are integrated from the mesh lathe profiles (Villa hull + dome as a half-ellipse; Seat lathe + seat), not from rendered pixels. On foot uses a body-plus-helmet estimate.
- **Contrast** comes from a heuristic (98th-percentile vs median luminance in four HUD regions), so the worst values may include scenery. The median of 7.5:1 is robust; the 2.1:1 worst case should be confirmed by eye.
- **Screenshot tour:** at seed 42 the scripted Snatcher sequence failed, because the Villa had retreated, so the Snatcher-siphon shots were dropped. The peak-tension shots come from the BeamOnly seed 4 replay instead (deterministic, same ticks as the headless run).
- **Mobile web:** emscripten is not on the box, so no browser run was done. The touch numbers come from the engine's touch layout code headless, on main, without PR #2.
- **Prototype attribution:** C changes behaviour (fewer walks) and so shifts sentry exposure. The hits-per-lock change attributed to D is confounded with it.
