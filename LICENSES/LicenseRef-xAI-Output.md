## Attribution

Every generated asset is credited **"Created with Grok"** in
[ATTRIBUTION.md](../ATTRIBUTION.md), and its `.meta.lua` sidecar records the
tool, model, prompt id, full prompt, date and processing steps.

## Prompts

Every prompt used for this project, kept or discarded, is logged in
[`art/prompts/log.jsonl`](../art/prompts/log.jsonl) (one JSON object per
line: id, date, tool, model, aspect ratio, prompt, kept, output, notes).
